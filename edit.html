Edit PDF

Coming soon

Edit your PDF directly in your browser. The editor is not built yet — this page reserves its place and describes the plan so the UI doesn’t need restructuring later.

Features planned

  • ➕ Add text
  • ✏️ Draw
  • 🖍️ Highlight
  • 🖼️ Add images
  • ✍️ Add signature
  • ⬛ Add shapes
  • 🔁 Rotate pages
  • 🗑️ Delete pages
  • ↕️ Reorder pages

Planned approach: pages render in the browser, edits are collected as an overlay layer, and the finished PDF is generated in the cloud. True in-place editing of existing PDF text comes later, if ever.
